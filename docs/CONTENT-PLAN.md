# 内容实现清单

对照原版 NetHack 的内容，逐项记录本作的实现状态。
目的是让「还差什么」一目了然，每轮迭代可以按优先级取下一项。

图例：**已完成**、**部分**（有数据或雏形，机制不全）、**未实现**。

## 一、角色与成长

| 项目                             | 状态   | 说明                                                        |
| -------------------------------- | ------ | ----------------------------------------------------------- |
| 13 职业 / 5 种族 / 3 阵营 / 性别 | 已完成 | 数据取自 `src/role.c`，创建界面按原版限制提供选项           |
| 六项属性与初始装备               | 已完成 | 属性影响负重、命中、施法成功率                              |
| 经验、等级、升级                 | 已完成 | 升级提升上限并恢复生命，阈值与 `newuexp` 一致               |
| 技能系统（武器、法术流派熟练度） | 已完成 | 武器与法术流派都按使用次数成长，降低施法失败率并加命中/伤害 |
| 祈愿与祈祷                       | 已完成 | 祈祷按神坛归属、阵营记录与冷却结算，可治疗与解除石化        |

| 许愿                             | 已完成 | 许愿魔杖与魔法灯输入物品名，支持中英文、数量前缀与金币      |
| 阵营记录与神祇态度               | 已完成 | 击杀按阵营加减记录，显示在状态栏；祭坛归属随机生成          |
