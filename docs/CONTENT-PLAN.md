# 内容实现清单

对照原版 NetHack 的内容，逐项记录本作的实现状态。
目的是让「还差什么」一目了然，每轮迭代可以按优先级取下一项。

图例：**已完成**、**部分**（有数据或雏形，机制不全）、**未实现**。

## 下一批候选（按收益）

1. **怪物特殊攻击与抗性**：数据齐全，激活后战斗深度立刻提升。
2. **商店与金币**：让金币产生意义，同时补上原版重要的资源循环。
3. **地形设施效果**：喷泉、祭坛、坟墓已有模型与位置，补上踏入效果成本低。
4. **祈祷**：危机时刻的手段，需要先做阵营记录。
5. **宠物**：原版标志性机制，涉及 AI 与跟随。
6. **特殊楼层与任务线**：内容量最大的一项，建议放在机制补齐之后。
